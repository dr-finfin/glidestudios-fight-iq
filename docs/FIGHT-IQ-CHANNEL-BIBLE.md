# Fight IQ Channel Bible — v0.1

## Positioning
Fight IQ tells compelling stories about fighters, fights and rivalries. The channel is story-first, not a generic news or highlight channel.

## Core content pillars
1. Fighter stories
2. Rivalries
3. Fight stories
4. What happened to... / career arcs

## Editorial principle
The story is the product. Facts establish trust; pacing, conflict, stakes and character create retention.

## Initial episode structure
Hook -> Context -> Inciting event -> Escalation -> Major confrontation -> Consequences -> Legacy

## Production philosophy
- Original narration and storytelling
- Transformative analysis/context
- Strong visual continuity
- Tactical/diagram graphics where useful
- No dependence on unlicensed full-fight compilations

## Human gate
No automated public publishing during the MVP. Every episode requires approval until the system has demonstrated reliable output.
